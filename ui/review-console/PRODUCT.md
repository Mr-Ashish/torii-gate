# Product — Torii Run Console

## Register

product (Operate)

## Users

Engineers and operators who run Torii PR reviews (GHA or Modal). They open the console after a run to understand **what happened**, not to be sold a product. They need the PR, the verdict, the findings, the cost, the pipeline stages, and the agent trace in one place.

## Product purpose

Turn a Torii run package (review.md + meta + timings + usage + diff + agent-loop) into a scannable ops surface. Success: an operator can answer “what did Torii say, why, and what did it cost?” in under 30 seconds without opening five GitHub artifacts.

## Brand personality

Direct, operational, precise. Same voice as Torii’s review comments: no fluff, no “great job,” evidence first.

## Anti-references

- Purple-to-blue AI dashboards, Inter/Roboto everything, glassmorphism
- Nested cards and metric-hero templates
- Decorative sparklines, bounce animations
- Treating OpenUI generic chat chrome as the product

## Design principles

1. **Operate mode** — task first; brand lives in restraint and type.
2. **One source of truth** — the packed run bundle; no fake demo numbers.
3. **Depth by navigation** — tabs for PR / result / trace / cost, not stacked identical cards.
4. **Impeccable craft** — kinpaku lacquer system (DESIGN.md), not generic dark SaaS.
