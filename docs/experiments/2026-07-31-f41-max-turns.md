# Fire — F41 Hermes max_turns (2026-07-31)

## Problem

Hermes defaults to **500** tool-calling iterations per turn. A hung or thrashing
agentic PR review can burn OpenRouter spend even when F36 wall-clock (1500s)
has not fired yet. Torii had no iteration budget.

## Hermes inspiration

`agent.max_turns` / `--max-turns` / `HERMES_MAX_ITERATIONS` + “Iteration budget
exhausted” exit path in hermes-agent conversation loop.

## Ship

- `scripts/max_turns.py` resolve/detect (default **40**, `0`/`off` disables)
- `agent/config.yaml` `agent.max_turns: 40`
- `run-hermes-review.sh` passes `--max-turns`, rewrites config, writes
  `hermes-max-turns.env`, job-summary on hit
- `pack-run-for-ui.py` → `signals.max_turns_hit` + `loop` metrics
- Run Console Overview + Loop tab
- Workflow `vars.TORII_MAX_TURNS`, Modal env, install pack
