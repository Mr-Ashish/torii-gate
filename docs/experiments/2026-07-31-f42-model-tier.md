# Fire — F42 auto model tier (2026-07-31)

## Problem

Default review model is Claude Opus 5 (F26). Docs-only and tiny PRs still burn
premium tokens even when F38 path-skip is not enabled.

## Hermes / industry inspiration

H7 in hermes-inspired-roi.md: auto model tier by PR size (cheap first).

## Ship

- `scripts/model_tier.py` select (mode off|auto|cheap|full)
- Defaults: cheap=`openai/gpt-4.1-mini`, full=`anthropic/claude-opus-5`
- Tiny: ≤3 files and ≤12k diff bytes; docs-only path globs; truncated → full
- `run-hermes-review.sh` re-resolves after meta.env; writes `model-tier.env`
- pack-run signals + Run Console overview; workflow vars; Modal env; install pack

## Verify

```bash
pytest tests/test_model_tier.py tests/test_pack_run_for_ui.py -q
bash -n scripts/run-hermes-review.sh
TORII_MODEL_TIER=auto python3 scripts/model_tier.py select --path README.md --diff-bytes 100
```
