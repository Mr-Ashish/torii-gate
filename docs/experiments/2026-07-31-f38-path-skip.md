# Fire — F38 path-glob free skip (2026-07-31)

## Problem

Docs-only / changelog PRs on monorepos still pay full OpenRouter + Hermes cost.
Cooldown (F19) only stops re-triggers, not free path classes.

## Ship

- `scripts/path-skip-check.py` — all changed paths must match globs → skip paid run
- Opt-in `vars.TORII_SKIP_PATH_GLOBS` (`docs` preset or comma list); empty = off
- Force: `@torii review force` / workflow_dispatch
- Stub COMMENT review + rocket reaction + F37 labels when skipped
- Wired after sparse path list, before monorepo checkout

## Verify

```bash
pytest tests/test_path_skip_check.py -q
python3 scripts/path-skip-check.py --path README.md --globs docs; echo rc=$?
python3 scripts/path-skip-check.py --path src/a.py --path README.md --globs docs; echo rc=$?
```
