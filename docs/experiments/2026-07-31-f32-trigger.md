# Fire — F32 unified trigger (2026-07-31)

## Problem

Operators had three ways to start a review (GHA comment, `review-local.sh`,
`modal run --bit 3`) with no single entry; Run Console was view-only; Modal bit 4
(webhook doorbell) was still open.

## Ship

- `scripts/trigger-review.sh` print|local|modal
- Modal: `parse_enqueue_payload`, `plan_enqueue`, `enqueue_review`, `review_webhook`
- CLI bit 4 dry plan + optional `--spawn`
- Run Console **Run** tab + empty-state trigger panel
- Tests: `tests/test_trigger_review.py`

## Verify

```bash
bash -n scripts/trigger-review.sh
pytest tests/test_trigger_review.py tests/test_install_torii.py -q
cd ui/review-console && npm run build
# optional (needs modal token): modal run modal_app/app.py --bit 4
```
