# Pattern: install UX — one CLI + minimal pack

## Source
- AppSec install UX: time-to-first-signal is the product; dual entrypoints kill adoption.
- Loop Engineering: day-2 doctor habit over dump of internal flags.
- Scorecard dim **install UX (5.5)**: 5-minute path, smaller pack surface.

## Steal for Torii
1. `docs/INSTALL.md` — five steps only; required check `torii/gate`.
2. `install-torii.sh --minimal` excludes bench/eval/modal/heavy evolution + skill proposals.
3. `torii.py doctor` human summary on TTY; `--json` for machines/scorecards.
4. Kill dual tip (`torii_memory.py` next to `torii.py`) on install next-steps.

## Anti-pattern
Install footer listing three peer CLIs and a 40-line F-number doctor dump as the day-one experience.
