# Juice Shop–style synthetic demo (Torii F76)

**License:** original Torii demo code (same repo license).  
**Not** a copy or submodule of [OWASP Juice Shop](https://github.com/juice-shop/juice-shop).

Intentionally vulnerable Express-style snippets for **labeled offline/live
security-gate benchmarks**. Do not deploy.

Themes (mapped to common Juice Shop challenge classes):
- SQL/NoSQL injection in product search
- Reflected XSS in feedback
- Command injection via admin ping
- Hardcoded JWT secret
- Broken access control (IDOR) on order lookup
